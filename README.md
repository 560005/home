# 560005.town

A community directory of tacit local knowledge for northeast Bangalore (primarily Cooke Town and Richards Town) — services, places, and people that neighbours vouch for.

Built with [Zola](https://www.getzola.org). Data lives in [560005/edit](https://github.com/560005/edit) and gets pulled into static category and tag pages on each deploy. The [babashka](https://babashka.org) scripts used to generate the pages live in `bin/`.
